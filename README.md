# E-Billing-J2SE 🖥️
eBilling Management Application Software

## Overview 👀

eBilling Management Software is a desktop-based billing system developed using Java (J2SE) and Oracle Database. This software helps manage customers, products, and invoices efficiently.

## Features 🗃️

- **Customer Management**: Add, update, and delete customer details.

- **Product Management**: Maintain product information, including name, price, and stock.

- **Invoice Management**: Generate and manage invoices with automatic calculations.

- **Database Integration**: Uses Oracle Database for secure and efficient data storage.


## Technologies Used ⚙️

- **Java (J2SE)** – Core Java for application development

- **Oracle Database** – Data storage and management

- **JDBC** – Java Database Connectivity for seamless database interaction


## Installation 🔄

### Prerequisites ⏳

- Install JDK (Java Development Kit) (Version 8 or later).

- Install Oracle Database and configure a database instance.


### Setup Steps ⬇️

1. Clone the repository: git clone https://github.com/Shivam-Singh-Coder/E-Biling-J2SE.git
2. Change directory: cd E-Biling-J2SE
3. Configure database connection in the Java code (DBConnection.java).
4. Compile and run the application:
   A. javac EBiling.java
   B. java EBiling

## Usage 📦

1. Login into the system (if applicable).

2. Manage Customers – Add, update, or delete customer records.

3. Manage Products – Maintain product inventory.

4. Generate Invoices – Create and print invoices for customers.
